# PowerShell Knowledge Base

This folder contains PowerShell-related IT documentation.

## Common Troubleshooting

For PowerShell troubleshooting, check:

- PowerShell execution policy
- PowerShell version
- Module availability
- Command syntax
- PowerShell error messages

## Useful Commands

Common PowerShell troubleshooting commands include:

- Get-ComputerInfo
- Get-Service
- Get-Process
- Get-NetIPConfiguration
- Test-NetConnection
