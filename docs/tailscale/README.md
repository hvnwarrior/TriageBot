# Tailscale Knowledge Base

This folder contains Tailscale-related IT documentation.

## Common Troubleshooting

For Tailscale connectivity problems, check:

- Tailscale service status
- Device authentication
- Network connectivity
- Tailscale IP addresses
- Tailnet status

## Useful Commands

Common Tailscale troubleshooting commands include:

- tailscale status
- tailscale ping
- tailscale ip
- tailscale netcheck
